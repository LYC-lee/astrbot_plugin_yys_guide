# 阴阳师攻略助手（AstrBot 插件）

群聊里有人问「魂土怎么打」「须佐之男御魂配什么」，机器人自动去抓博主的新攻略，
用大模型整理成「阵容 / 御魂 / 打法 / 注意」的结构化卡片回出来。

命中缓存时秒回，没命中才联网抓，抓完写进缓存。

## 实测可用性（2026-11）

先把丑话说在前面，这几个平台的自由度差别很大：

| 平台 | 状态 | 说明 |
|---|---|---|
| 网易大神 | 开箱可用 | **图文攻略主力**。移动版用户主页走服务端渲染，HTML 里直接带 9 条最新动态，不需要 Cookie、不需要签名，连续请求实测 6/6 稳定 |
| B站 | 开箱可用 | 走 WBI 签名的 web 接口，游客 `buvid3` 就能搜。视频攻略最全 |
| 360 搜索 | 开箱可用 | 兜底搜索，无需 key |
| 微博 | 需填 Cookie | 无 cookie 会被拦（432）。填 `m.weibo.cn` 的 `SUB` 后可读 |
| NGA | 需填 Cookie | 现在强制登录（403「访客不能直接访问」）。填登录态 cookie 后可读 |
| 抖音 | 只解析链接 | 主页列表需要 `a_bogus` 签名，没做逆向。只能解析单条视频的文案和封面，失败就只给链接 |
| Bing | 不推荐 | 无 cookie 时中文查询会退化成完全不相关的结果（搜「阴阳师御魂」返回「阴阳」百科），已加相关性过滤兜底 |

也就是说：**不配任何 Cookie，网易大神 + B站 + 360 搜索已经能跑起来**，只是少几个来源。

### 网易大神能抓什么、不能抓什么

实测结论（2026-11）：

| 能力 | 结果 |
|---|---|
| 按作者抓最新动态 | ✅ 一次 9 条，带标题、时间、正文摘要、话题标签、封面图 |
| 单条详情页 | ✅ 有标题和摘要，但正文多为长图，文字量少 |
| 从 URL 反查作者 | ✅ `m.ds.163.com/user/<uid>` 里的 32 位 uid |
| 按关键词搜索 | ❌ 搜索页 404，所以这个源只支持「按作者跟」 |
| 圈子 / 话题流列表 | ❌ 404 |

它比 B 站强的地方在于**正文是图文全文**：带游戏内可直接粘贴的阵容码（`|TA|7fbefcd2...`）、
带具体配速（「全员大于 200 速锁普攻」）、带通关时间（「38S～45S」）。
B 站只能拿到视频简介，干货都在画面里，卡片上几乎没法用。

> ⚠️ 抓取时必须用**移动端 UA**。PC 的 `ds.163.com/user/...` 会 302 跳到移动版，
> 但带着 PC UA 跳过去拿到的是空壳页，一条 `feed-card` 都没有。


## 安装

1. 把 `astrbot_plugin_yys_guide` 整个目录放到 AstrBot 的 `data/plugins/` 下；
2. 在 WebUI 的插件管理里重载，或重启 AstrBot；
3. 打开插件配置页，按下面填一下。

依赖只有 `httpx`，AstrBot 本身已经带了。

## 配置

### 核心博主（最重要的一项）

`core_authors` 是 `template_list`，在 WebUI 里点「添加」选类型就行。

**默认已内置 4 位网易大神作者 + 4 位 B站 UP 主**，都是实测活跃的（最后核验：2026-11-04）：

| 平台 | 名称 | ID | 最新发布 | 方向 |
|---|---|---|---|---|
| 大神 | 槐夏三十 | `a9724e98c1cb4a4e931ebc3f467ea73d` | 今天 | 体服改动、名仕阵容、秘闻挂机，几乎日更 |
| 大神 | yys雯雯 | `aaa923436aa440df9ac1ee3f47387b99` | 2 天前 | 活动攻略、道馆阵容、每周日程表 |
| 大神 | Mico林木森（森森） | `b6b5bc8277e34f69aeca018db0081397` | 3 天前 | 超鬼王、契灵、极·胧车，攻略体系化 |
| 大神 | 姝酱的小本本 | `6f3189e218fb4f6492b99efcbbd79119` | 7 天前 | 活动三套阵容码 + 规则奖励，图文正文可直接抽 |
| B站 | 流沙河底 | `297721993` | 2 天前 | 道馆进攻阵容、真蛇、带图文方案码 |
| B站 | 姝酱的小本本 | `687489264` | 7 天前 | 活动三套阵容 + 规则奖励 + 抽卡建议 |
| B站 | 徐小侠丶 | `12381891` | 7 天前 | 新式神技能解析、强度前瞻 |
| B站 | 在下小贱哥哥 | `102859066` | 12 天前 | 超鬼王、式神养成 |

**网易大神**：填 32 位十六进制的 `uid`，不是昵称。
主页地址 `https://m.ds.163.com/user/a9724e98...` 里那串就是。

**B站**：填数字 `mid`，不是昵称。
空间页地址 `https://space.bilibili.com/123456` 里的 `123456` 就是 mid。
`topics` 可留空（表示这个 UP 主的都收），也可以填「御魂,阵容」做过滤。

**微博**：默认没有配。原因很实际——微博现在强制登录，游客请求直接 432，
配了也抓不到，只会在配置里多两个永远不出结果的项。
如果你有自己的 Cookie，可以加上 `cookies.weibo` 再往里加微博博主。
填数字 `uid`（主页 `https://weibo.com/u/1234567890` 里的数字），昵称改来改去不能当 id 用。

> 💡 同一个人可能在多个平台都有号。比如 yys雯雯 微博有大神也有，
> 微博抓不到就配大神那个，内容是一样的，而且大神不用 Cookie。

> ⚠️ 姝酱的小本本 是跨平台双开，两边默认都配了：大神发图文（有正文、有阵容码），
> B站发同名视频。**同一篇攻略可能在卡片里出现两次**（一条图文一条视频）。
> 去重只按「同平台 + 同作者 + 标题近似」做，跨平台刻意不合并——
> 视频有画面演示、图文有文字方案，留着两种形态各有各的用处。
> 只想看图文的话，把 B站那条（`687489264`）删掉即可；反之亦然。

NGA 和抖音不支持按作者抓，所以没有对应模板。

**博主内容优先，但不会霸屏**：排序时「命中当前话题的核心博主内容」排最前，
其次是别的博主的对题内容，最后才是全网搜索。博主在聊别的东西时不会顶掉对题结果。
判断「是不是核心博主」时先比备注名，比不中再比 uid / mid——
所以就算你把备注名写成「森森」，而大神返回的作者名是「Mico林木森」，加权也不会失效。

**同一平台、同一标题只留一条**：作者经常把一篇攻略拆成几条发（正文只改个开头），
按 id 去重拦不住，卡片里会出现两条几乎一样的。现在按「平台 + 标题」再去一次重。
跨平台不去重——同一篇内容在 B站是视频、在大神是图文，两种形态都留着。

**B站空间接口有 IP 级配额**（实测连续请求十几个账号就会 `-799 请求过于频繁`）。
拿不到时插件会自动改用「搜索作者名 + 按 mid 过滤」兜底；如果两条路都失败，
卡片顶部会明确写「N 个博主的接口本次被限流，以下为缓存/全网搜索结果」，
不会让你误以为是博主没更新。

**网易大神没有这个问题**，实测连续 6 次请求全部 200，所以它是更稳的那一路。

### 触发方式

`trigger_mode` 有两个值：

- `strict`（默认）：消息里得出现「阴阳师 / yys / 痒痒鼠」这类锚点词，
  或者「魂土」这种只有阴阳师玩家才懂的实体词 + 意图词（攻略、怎么配、推荐……）。
  群里随口说「这个阵容很强」不会触发。
- `loose`：命中任何实体词就回复。响应积极，但更容易刷屏。

另外有 `cooldown_seconds`（默认 60 秒），同一个群短时间内重复问只回一次。

**答完会把事件掐掉**（`event.stop_event()` + `should_call_llm(False)`）。
不掐的话，一条 `@机器人 魂土阵容` 会被你的插件回一次、再被默认 LLM 回一次，
群里看起来就像两个机器人在抢答。这条只在我们真的出了卡片之后才执行，
所以不相关的话照样交给别的插件/大模型处理。

### 搜索准不准

一句话：**宁可少给，不给错**。

早期的做法是「先拿博主的 9 条最新动态，凑够 5 条就完事」，于是问「魂土阵容」
会收到「本周活动日程表」「葛叶式神改动」，而摘要栏还老实写着「未涉及阵容内容」。
根因有两个，都修了：

1. **用来判断相关性的词里混进了意图词**。「阵容」几乎每篇攻略标题里都有，
   拿它匹配等于没匹配。现在关键词分两档：
   强词（魂土、须佐之男）命中就是 2 级，弱词（御魂、斗技、活动）是 1 级，
   意图词一律不参与判断。
2. **只看标题，不看正文**。大神的「摘要」其实是整篇正文，一篇 PVE 合集的正文里
   必然列出「魂十、魂土、魂王、结界突破……」，拿正文判断的话它会被当成魂土攻略。
   标题里没这个词，就是没在讲这件事。

`strict_relevance`（默认开）控制最后一道闸：一条 1 级以上都没有时，
直接回「没找到」，而不是拿无关内容凑满格子。想退回旧行为把它关掉即可。

博主那边不够数时，会拿强词重新去站内搜（`阴阳师 魂土`，
实测比 `阴阳师 魂土 阵容 御魂` 精准得多——多堆词只会把大杂烩顶上来）。
`author_fetch_limit`（默认 12）控制先从博主的多少条里筛。

### 定时预热

`warmup.times` 默认 `["09:00", "20:00"]`，到点自动按 `topics` 里的话题抓一轮，
写进缓存。用户触发时直接读缓存，秒回。

`warmup.push_umo` 留空就是**只预热不推送**，不会在群里刷消息。
想让机器人主动发简报的话，在这里选一个会话。

### 摘要

`summary.use_llm` 默认开。走 AstrBot 已配置的模型，把原文提炼成四个字段。

模型没配、超时（默认 40 秒）、返回的 JSON 格式不对——都会自动退回规则抽取，
只截原文前 160 字，绝不编造。卡片底下会标注「大模型摘要不可用，以下为原文节选」。

## 指令

| 指令 | 作用 |
|---|---|
| `/yys 御魂` | 手动查询，绕过别名匹配，直接用这个词搜 |
| `/yys 须佐之男御魂` | 同上，可以带式神名 |
| `/yys状态` | 看缓存条目数、各来源分布、下次预热时间 |
| `/yys刷新` | 立刻预热一轮 |

直接发消息触发也可以，比如「yys 魂土阵容推荐」会自动响应。

## 卡片长什么样

```
▎阴阳师 · 魂土阵容
　5 条 · 整理于 11-03 23:44

　1. 魂土11s双白蛋食雪紧
　　B站 · @某UP主 · 2 小时前
　　阵容：雪御前 / 紧那罗 / 食灵 / 双白蛋
　　御魂：大于158狂歌雪，狂荒紧那罗
　　打法：一速雪御前拉条，紧那罗接大招收尾
　　注意：需要一定练度
　　链接：https://www.bilibili.com/video/BV1xx
──────────────
　2. ...
```

标题里的「魂土阵容」是**你原话**，不是内部话题名。
以前这里显示「御魂」，用户会以为自己搜错了东西。

`render.style` 可以换成 `markdown`（Discord / Telegram / 飞书）或 `plain`。
缩进用的是全角空格，因为 OneBot 适配器会对纯文本做 strip，半角缩进在某些渠道会塌掉。

## 它是怎么工作的

```
消息进来
  └─ 别名匹配（实体词定话题 + 锚点词防误触发 + 关键词分强弱档）
      └─ 查 SQLite 缓存（够数且对题直接返回）
          └─ 没命中才抓：博主的 N 条里按关键词筛 → 不够再拿强词站内搜
              └─ 过滤营销内容（代练、卖号、私服、SEO 落地页）
                  └─ 补正文 → 写缓存
                      └─ 排序：对题（2 级 > 1 级）> 核心博主 > 站内 > 时间
                          └─ 丢弃 0 级：标题里没有关键词的不要
                              └─ 去重：同 id → 跨平台同名 → 同作者近似标题
                                  └─ 限流：每个作者最多 2 条，避免一人霸榜
                                      └─ LLM 摘要（失败降级规则抽取）
                                          └─ 渲染卡片 → 终止事件传播
```

每一层都可以失败：某个平台挂了、模型超时、缓存没命中，最终一定还能给用户一个能看的结果。

去重和配额是踩出来的，不是设计时想到的：

1. **同 id**：同一个动态重复抓到时合并。
2. **跨平台同名**：同一篇攻略被博主同步发到大神和 B站，两条一模一样的标题
   看起来像出了 bug。标题完全一致、或一个是另一个的「主体」时只留一条。
3. **同作者近似标题**：还有一种更隐蔽的——「【契灵弃置方案】视频使用教学，一键解决爆仓烦恼」
   和「【契灵弃置方案】一键解决爆仓烦恼」，标题不同但说的是同一件事。
   去掉开头的【标签】后如果一个包含另一个，就只留信息多的那条。
   这里只认「互相包含」不认「前缀相同」，否则「荒川百战 3+2」和「荒川百战 2+3」
   这种同系列不同攻略会被误合并。
4. **单作者最多 2 条**：你配了 7 个博主是想看不同人的思路，
   结果最活跃那位一次更五条把卡片占满，另外 6 个就白配了。
   挑不满再放宽补齐，所以只有一个作者有内容时仍然能填满。

**搜索引擎结果是兜底，不是正餐**。站内（大神/B站/NGA/微博/抖音）凑够 5 条时，
搜索来的条目直接不用。原因很实际：搜索结果的标题常被 SEO 拼成
「xxx\_\_九游手机游戏」「xxx - 游戏鸟」，点开也常是聚合页，一条条加规则永远追不完。

## 已知限制

- **网易大神只能按作者跟，不能按关键词搜**。搜索页和圈子流都是 404，
  所以想覆盖更多内容只能多加作者，没法像 B站那样做话题兜底搜索。
- **大神的正文是长图**。文字部分就是「标题 + 一小段导语」，
  真正的阵容图在图片里。插件不下载图片（`render.show_cover` 只带封面），
  想看完整方案还是要点开链接。
- **大神的时间是相对文案**，页面不给时间戳。`昨天23:00`、`11/1`、`3小时前`
  这些都要自己推算，跨年时 `12/30` 会被推成去年（1 月看到不会变成未来时间）。
  推算逻辑在 `yys_fetchers/ds163.py` 的 `parse_ds_time`，有 14 项用例覆盖。
- **微博不填 Cookie 就是 0 条**。搜索接口和用户时间线都要登录态，
  游客请求返回 432/403。插件会自动跳过（不发无用请求），但也就拿不到内容。
- **NGA 现在也强制登录**。游客访问 `bbs.nga.cn` 返回 403「访客不能直接访问」，
  必须填 `cookies.nga`。阴阳师主版是 `fid=538`（不是 582/703，那两个是互助和茶馆）。
- **B站空间接口是 IP 级配额**。短时间内连续抓多个博主会 `-799`，
  插件已加 8 秒冷却 + 搜索兜底，但博主数量建议控制在 6 个以内。
- **抖音只解析链接**。主页作品列表要 `a_bogus` 签名，这个没做逆向。
  插件也不做视频语音转写——token 消耗不值当。要单条视频的文案和封面，
  把分享链接丢进去能解析出来，解析不出来就只给链接。
- **B站视频没有字幕正文**。字幕接口需要登录态签名，所以 B站条目主要靠
  标题 + 视频简介。攻略的干货其实在视频画面里——这也是为什么加了大神：
  大神的图文正文能直接把阵容码写进卡片，比视频简介有用得多。
- **360 / Bing 的 HTML 结构随时会变**。解析用的是正则，跑不通时看日志里
  `[yys-guide]` 开头的 warning。
- **B站接口要 WBI 签名**，签名的混淆表自带时效性。如果哪天全线报 `-352`/`-403`，
  大概率是官方又换了表，需要更新 `yys_core/bili_wbi.py` 里的 `MIXIN_KEY_ENC_TAB`。
- **大神的页面结构也可能变**。它是靠 `div.feed-card` 的固定 class 解析的，
  哪天改版就会解析出 0 条。日志里会出现「大神用户页没解析到动态（HTML N 字符）」，
  看到这条就说明要改 `ds163.py` 里的正则了。

## 测试

全部在**插件目录内**执行（脚本会自动定位插件根目录，放在哪一层都能跑）：

```bash
# 纯逻辑（stub 掉 astrbot，不联网）
python tests/test_logic.py

# 搜索准确度：24 项（关键词分级 / 相关性打分 / 不再凑数 / 终止事件传播）
python tests/test_accuracy.py

# 网易大神抓取器：52 项（时间解析 / 标题拆分 / HTML 解析 / 真实抓取）
python tests/test_ds163.py
python tests/test_ds163.py --offline    # 只跑离线部分

# 各平台真实可用性，跑完能看清谁能用谁要 Cookie
python tests/test_live_platforms.py

# 端到端：模拟一条群消息走完全流程
python tests/test_end_to_end.py

# 用 _conf_schema.json 里的真实默认配置跑一遍，看装好之后默认长什么样
python tests/verify_default_config.py

# 校验配置里所有博主的 mid/uid 是否有效、最近有没有更新
python tests/check_authors.py
python tests/check_authors.py --only ds163     # 只看大神
```

`check_authors.py` 直接读 `_conf_schema.json` 里的默认名单，改完配置跑一下就知道有没有填错，
不用等到线上才发现卡片是空的。它还会标出超过 30 天没更新的号。
